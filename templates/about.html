ABOUT THE PROJECT

Turning tweets into insights.

A machine learning project that identifies sentiment in text.

Project Overview

TweetSense AI analyzes tweet text and predicts whether the sentiment is positive or negative.

Machine Learning

The project uses a trained classification model with TF-IDF text features.

Technology Stack

Python, Flask, Pandas, Scikit-learn, TF-IDF and HTML/CSS.

How it works

01. Enter a tweet into the input box.

02. The text is cleaned and converted into TF-IDF features.

03. The trained model predicts the sentiment.

04. The website displays the prediction.
